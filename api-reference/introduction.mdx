## Welcome

Welcome to the CreptaPay API Reference. Here you can find details for integrating payment creation, wallet retrieval, and signature verification.

## Authentication

All API endpoints are authenticated using API keys passed in the headers.

```json
"security": [
  {
    "ApiKeyAuth": []
  }
]
```
